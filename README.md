# Node.js Study Hub

موقع عربي تفاعلي للمذاكرة ومراجعة Node.js وBackend Internals، مبني باستخدام Next.js وTypeScript.

## المحتوى الحالي

- Node.js Runtime وV8
- Modules: CommonJS / ESM / Module Cache
- File System: Sync / Async / Promises
- Buffer وUTF-8
- Streams وBackpressure
- npm وpackage management
- libuv وThread Pool
- Event Loop
- Microtasks وprocess.nextTick
- Worker Threads

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح:

```text
http://localhost:3000
```

## البناء للإنتاج

```bash
npm run build
npm start
```

المشروع يستخدم App Router وواجهة RTL عربية متجاوبة مع Dark Mode والبحث وتتبع تقدم المذاكرة.
